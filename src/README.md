# موقع شركة الستائر الفاخرة

موقع إلكتروني فاخر لشركة ستائر في المملكة العربية السعودية بتصميم بسيط وأنيق.

## المميزات

- ✨ تصميم فاخر وأنيق بألوان هادئة (أبيض، بيج، ذهبي فاتح)
- 🎨 استخدام خط Cairo العربي الأنيق
- 📱 تصميم متجاوب بالكامل لجميع الأجهزة
- 🖼️ كاروسيلات جميلة لعرض الصور والمنتجات
- 🧭 نظام تنقل متطور مع قوائم منسدلة
- 📄 صفحات متعددة: الرئيسية، من نحن، أنواع الستائر، أخبارنا، اتصل بنا

## التقنيات المستخدمة

- **React 18** - مكتبة واجهة المستخدم
- **TypeScript** - للحصول على كود آمن ومنظم
- **Tailwind CSS v4** - للتصميم والتنسيق
- **Vite** - أداة بناء سريعة ومتطورة
- **ShadCN/UI** - مكونات واجهة مستخدم جاهزة
- **Embla Carousel** - للكاروسيلات السلسة
- **Lucide React** - للأيقونات الجميلة

## البدء في التطوير

### المتطلبات

- Node.js 18 أو أحدث
- npm أو yarn أو pnpm

### التثبيت

1. استنسخ المستودع أو قم بتنزيل الملفات:
\`\`\`bash
git clone <repository-url>
cd saudi-curtains-website
\`\`\`

2. قم بتثبيت الحزم:
\`\`\`bash
npm install
\`\`\`

أو باستخدام yarn:
\`\`\`bash
yarn install
\`\`\`

أو باستخدام pnpm:
\`\`\`bash
pnpm install
\`\`\`

### تشغيل المشروع

للتشغيل في وضع التطوير:
\`\`\`bash
npm run dev
\`\`\`

سيعمل المشروع على: http://localhost:5173

### البناء للإنتاج

لبناء المشروع للإنتاج:
\`\`\`bash
npm run build
\`\`\`

لمعاينة نسخة الإنتاج:
\`\`\`bash
npm run preview
\`\`\`

## التخصيص

### تغيير الألوان

يمكنك تخصيص الألوان من خلال ملف \`styles/globals.css\` في قسم \`:root\`.

### إضافة صفحات جديدة

1. أنشئ ملف صفحة جديد في مجلد \`pages/\`
2. أضف الصفحة إلى نظام التوجيه في \`App.tsx\`
3. أضف رابط التنقل في \`components/Navigation.tsx\`
